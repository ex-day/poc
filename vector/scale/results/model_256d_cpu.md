# 件数を増やしたときのベクトル検索（model・256次元）

- 実行日時：2026-10-01 14:40
- 環境：MacBook Pro（M4 Pro）・Docker（Darwin 25.6.0 arm64 arm）
- PostgreSQL 18.6 (Debian 18.6-1.pgdg12+2)／pgvector 0.8.6。shared_buffers=128MB、max_parallel_workers_per_gather=2
- HNSW：m=16、ef_construction=64。問い 200 件、上位 10 件。条件ごとに暖機 10 件、3 回くり返し（回ごとに条件と問いの順番を入れ替え）
- 時間は「p50／p95（ms）」。p95 は nearest-rank。再現率・1位・順は最後の回の結果
- 1位：1位が全件比較の1位と一致した割合。順：距離の小さい順に並んでいた割合。どちらも 1.00 のときは省略
- （全件走査）：測定と同じ SQL の実行計画に、HNSW のインデックスが現れなかった（件数が少ないとプランナーが全件走査を選ぶ）
- モデル：cl-nagoya/ruri-v3-30m（デバイス cpu、バッチ 32）
