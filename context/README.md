# 会話の投稿どうしの近さを見る（[ex-day/poc#2](https://github.com/ex-day/poc/issues/2)）

会話を話題（文脈）ごとに分けられないかを考えるための、最初の小さな実験です。短い会話の投稿どうしや、積み重なった会話の文脈と新しい投稿が、どのくらい「近い」と判定されるかを、埋め込み（Ruri v3、e5）で見ます。

Ruri v3 は用途ごとに先頭に付ける言葉が決まっているので、「意味」（なし）と「話題」（`トピック: `）の両方で比べます。

## 題材

[`posts.json`](posts.json) の7つの投稿です（利用イメージで、実在の人物・出来事とは関係ありません）。

| 投稿 | 返信先 | 本文 | 正解の話題 |
|---|---|---|---|
| P1 | － | 桜木町から山下公園まで散歩したよー、天気よかったから気持ちよかった | T1・T2 |
| P2 | P1 | 天気よくてよかったね、海辺だし風はどうだった？ | T1（天気） |
| P3 | P2 | そこまで吹いてなかったよ、まぁでも海近いしビル風もあるしね | T1 |
| P4 | P3 | そうだよね | T1 |
| P5 | P1 | どこあるいたの？ | T2（経路） |
| P6 | P5 | ロープウェイのところ | T2 |
| P7 | P6 | 汽車道か、赤レンガよった？ | T2 |

気になっていること：

- 「そうだよね」や「どこあるいたの？」のような短い投稿は、何かと近くなるのか
- 「汽車道」（場所・道）と「ロープウェイ」（乗り物）は近いと判定されるのか

## 動かし方

```bash
cd context
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python similarity_demo.py                                   # 既定：Ruri v3（30m）
python similarity_demo.py cl-nagoya/ruri-v3-70m intfloat/multilingual-e5-small   # モデルを指定
```

`vector/` の `.venv` があれば、それをそのまま使っても構いません。

## 出るもの

1. 投稿どうしの近さの表（1.00 に近いほど近い）
2. 投稿ごとに、いちばん近いほかの投稿（同じ話題なら ○、違えば ×、どれとも近さが 0 なら －）
3. 積み重なった文脈と比べる：新しい投稿を、それより前の各投稿までの会話の積み重ね（返信先をたどったもの。例：P3 を「P1+P2」と、P6 を「P1+P5」と）と比べ、どの文脈がいちばん近いか。文脈の話題は、その文脈の最後の投稿の話題とする。「返信先の文脈」も並べて表示するので、返信先の文脈がいちばん近くなったかも見られる
4. 単語どうしの近さ（`posts.json` の `words`。汽車道、ロープウェイ、赤レンガ等）

## 埋め込み（Ruri v3・30m）での結果（投稿ごとに比べた場合）

- 同じ話題の投稿がいちばん近かった数は、Ruri（意味）が 5/7 で最もよかった。「天気よくてよかったね、風はどうだった？」と「そこまで吹いてなかったよ」（0.90）のように、単語が一致しなくても天気の話どうしをつなげた
- P6「ロープウェイのところ」と P7「汽車道か、赤レンガよった？」は、お互いにいちばん近かった（0.85）
- P4「そうだよね」と P5「どこあるいたの？」は外れた。中身ではなく、「短い口語の文」という雰囲気どうしで近くなった
- 点数は 0.79〜0.90 の狭い範囲に固まり、差はわずか
- Ruri の「話題」（`トピック: `）は 4/7 で、「意味」より悪かった（7件だけなので決めつけない）
- 単語どうしでは、汽車道は遊歩道（0.88）、ロープウェイは電車（0.89）にいちばん近く、「道」と「乗り物」として見分けているように見える。汽車道とロープウェイは 0.84

## 積み重なった文脈と比べた結果（Ruri v3・30m）

- 「意味」「話題」とも 5/6
- P6「ロープウェイのところ」は、返信先の文脈「P1+P5」（どこあるいたの？）がいちばん近くなった。投稿だけで比べたときは後から来る P7 がいちばん近かったが、問いへの答えとして読むと経路の話になった
- P3・P4・P7 も、返信先の文脈がいちばん近かった。返信先をたどった文脈と、ベクトルでいちばん近い文脈がほぼ一致した
- 外れたのは P5「どこあるいたの？」だけ。どの文脈とも 0.83 前後で横並びで、決め手がなかった。P5 は P1 に返信して、天気とは別の「経路」の話題を始めた投稿で、前のどの文脈にも属さないのが正しいとも言える
- 点数の差はとても小さい（P6 は 0.82 が並び、P7 も 0.84 が並ぶ）。ベクトルは主役ではなく、返信先で決めたことを確かめる役に向きそう
