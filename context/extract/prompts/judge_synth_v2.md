# わかってきたこと・まだわかっていないことを、正解と照らし合わせる

ex-day は、場所について人が投稿し、返信し合うサービスです。会話から AI が書いた「わかってきたこと」と「まだわかっていないこと（問い）」を、人が書いた正解と照らし合わせてください。

## 正解の見方

正解の各項目には、次があります。

- `from_conversation`：会話から読める、わかってきたこと。照らし合わせるのはこれだけです。
- `local_knowledge`：人の土地勘で足したこと。AI には書けないので、照らし合わせに使いません（AI の文にこれがなくても、外れにしません）。
- `priority`：`want`（拾いたい）／`undecided`（未決）／`exclude`（知見にしないもの）
- `questions`：答えが付けば確かになる問いの一覧（ないこともある）。`optional` が true の問いは、出ても出なくてもよい

## 判定すること

正解の項目ごとに：

- `match`：AI のわかってきたことの中に、同じことを言っているものがあるか。
  - `一致`：言っていることがおおむね同じ（言い回しの違い、まとめ方の違いはよい）
  - `一部`：一部だけ言っている、または、ほかの話とまぜて要点がぼやけている、時期や確かさ（事実か説か）を取り違えている
  - `なし`：ない
- `by`：対応する AI のわかってきたことの id（複数でもよい）
- `questions`：正解の問いごとに、AI の問いの中に同じことを確かめる問いがあるか。`{"q": 正解の問いの番号（0 から）, "match": "一致／一部／なし", "by": [AI の問いの id]}` の一覧。正解に問いがなければ空
- `note`：一部・なしのとき、短く理由を書く

AI の項目ごとに：

- 正解のどれにも対応しない AI のわかってきたこと・問いを挙げ、次のどちらかを付けます。
  - `妥当`：正解にはないが、会話から言えて、場所について役に立つ
  - `余計`：会話から言えない、言いすぎ、または場所について役に立たない
- `一致`にする前に、AI の文が会話より言いすぎていないか（会話にない店・数・断定を足していないか）を確かめます。言いすぎていれば `一部` にし、`note` に書きます。

## 入力

- 会話：投稿の一覧
- 正解：一覧
- AI の出力：わかってきたこと（`findings`）と問い（`questions`）

## 出力

次の形の JSON を、指定されたファイルに書いてください。説明の文章は要りません。

```json
{
  "conversation": "会話の名前",
  "expected": [
    {"id": "K1", "match": "一致", "by": ["W3"], "questions": [{"q": 0, "match": "一部", "by": ["Q2"]}], "note": ""}
  ],
  "extra_findings": [{"id": "W9", "label": "妥当", "note": ""}],
  "extra_questions": [{"id": "Q7", "label": "余計", "note": ""}]
}
```

- `expected` には、正解のすべての項目を入れます。
