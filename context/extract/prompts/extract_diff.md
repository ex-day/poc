# 新しい投稿から知見を取り出す（差分）

ex-day は、場所について人が投稿し、返信し合うサービスです。会話に新しく届いた投稿（対象の投稿）を読んで、あとからその場所を訪れる人や調べる人の役に立つ「知見」を取り出してください。知見ごとに、根拠になった投稿の id を残します。

対象の投稿ごとに、その前の投稿のうち関係のありそうなもの（文脈）を一緒に渡します。文脈の投稿からは、すでに知見を取り出してあります。

## 知見とは

- 1つの知見には、1つの主張だけを書きます。2つ以上の主張が入るなら、分けます。
- その文だけを読んで意味が分かるように書きます。「あそこ」「その店」「それ」のような指す言葉は、会話から分かる名前や場所に置き換えます。会話から分からなければ、分からないままにします（地名や店名を推測で足さない）。
- 会話で述べられていないことは書きません。一般的な知識で補いません。
- 複数の投稿を合わせて初めて言える主張は、1つの知見にまとめます（例：「どこを歩いたの？」→「ロープウェイのところ」）。
- 次のものは取り出しません。
  - あいさつ、相づち、冗談だけのやり取り
  - 場所と関係のない雑談
  - 投稿した人自身についての情報（住んでいるところ、生活など）

## 各項目

- `content`：主張。日本語の1文。
- `kind`：次のどれか1つ。
  - `事実`：場所・店・道・地名などについての情報（あった、なくなった、混む、見える、など）
  - `体験`：誰かがその場所でしたこと、見たこと、食べたこと
  - `評価`：良い、高い、怖い、行きにくいなどの感想や意見
  - `疑問`：会話の中で答えが出ていない問い
- `place`：主張の対象の場所。会話に出てきた名前で書く。分からなければ `null`。
- `when`：いつの話か（今、昔、春、夕方など）。会話から分かるときだけ書く。分からなければ `null`。
- `src`：その主張を支える投稿の id。次の投稿を、すべて挙げます。
  - 主張の中身が書かれている投稿
  - 主張を読み取るのに欠かせない投稿（問いに答えた投稿の、問いの側など）

  話のきっかけになっただけの投稿や、相づちは入れません。

## 対象の投稿と文脈

- 知見は、**対象の投稿**に書かれている主張から取り出します。文脈の投稿だけに書かれている主張は、取り出しません（すでに取り出してあります）。
- 文脈の投稿は、対象の投稿の「あそこ」「その店」「それ」が何を指すかを決めるため、問いに答えた投稿の問いの側を知るために使います。そのために欠かせない文脈の投稿は、`src` に挙げます。
- `place` は、この会話が属する場所です。「ここ」「この辺」が `place` を指すことがあります。

## 入力

- `place`：会話が属する場所
- `targets`：対象の投稿の一覧。各項目は `post`（対象の投稿：`id`、`day`、`author`、`reply_to`、`text`）と、`context`（文脈の投稿の一覧。返信の鎖と、直前の数件）

## 出力

次の形の JSON を、指定されたファイルに書いてください。説明の文章は要りません。

```json
{
  "conversation": "会話の名前",
  "facts": [
    {"id": "F1", "content": "...", "kind": "事実", "place": "...", "when": null, "src": ["P4", "P5"]}
  ]
}
```

- `id` は F1, F2, F3… の順に付けます。
- 知見がなければ `"facts": []` にします。
