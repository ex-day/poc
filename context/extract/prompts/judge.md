# 知見と、その根拠の投稿を確かめる

ex-day は、場所について人が投稿し、返信し合うサービスです。会話から取り出した「知見」（1つの主張）と、その根拠として挙げた投稿（`src`）が正しいかを確かめてください。

## 確かめること

知見ごとに、次を判定します。

- `verdict`：主張が会話の内容と合っているか。
  - `正しい`：会話の内容どおり
  - `一部`：おおむね合っているが、言いすぎ、足りない限定、取り違えがある
  - `誤り`：会話の内容と合わない、または会話にない
- `support`：`src` に挙げた投稿のうち、主張を支えている投稿。
- `extra`：`src` に挙げた投稿のうち、主張を支えていない投稿（根拠の過剰）。
- `missing`：`src` に挙げていないが、主張を支えている投稿（根拠の漏れ）。
- `note`：判定の理由。一部・誤り・過剰・漏れがあるときに、短く書く。

「主張を支える投稿」とは、次のどちらかです。

- 主張の中身が書かれている投稿
- 主張を読み取るのに欠かせない投稿（問いに答えた投稿の、問いの側。指す言葉が何を指すかを決める投稿など）

話のきっかけになっただけの投稿、相づち、同じことを繰り返しただけで主張に何も足さない投稿は、支える投稿に入れません。

あわせて、会話全体を見て、どの知見にも入っていない情報を挙げます。

- `uncovered`：場所についての情報（事実・体験・評価・答えの出ていない問い）が書かれているのに、どの知見にも反映されていない投稿。あいさつ、相づち、冗談だけの投稿、投稿した人自身についての情報は入れません。

## 入力

- 会話：投稿の一覧（JSON）。各投稿は `id`、`day`、`author`、`reply_to`、`text`。
- 知見：一覧（JSON）。各知見は `id`、`content`、`src`。

## 出力

次の形の JSON を、指定されたファイルに書いてください。説明の文章は要りません。

```json
{
  "conversation": "会話の名前",
  "facts": [
    {"id": "F1", "verdict": "正しい", "support": ["P4", "P5"], "extra": [], "missing": [], "note": ""}
  ],
  "uncovered": [
    {"post": "P9", "info": "取りこぼした情報を短く"}
  ]
}
```

- `facts` には、入力のすべての知見を入れます。
