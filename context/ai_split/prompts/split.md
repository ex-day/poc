# 会話の投稿を話題に振り分ける

ex-day は、場所について人が投稿し、返信し合うサービスです。1つの会話（同じ場所のスレッド）の中で、話はいくつもの「話題」に分かれていきます。会話の投稿を読んで、どの投稿がどの話題かを決めてください。

## 話題とは

- 話題は、同じ対象（その場所にある特定のもの、出来事、歴史、行き方、食べたものなど）についてのやり取りのまとまりです。
- 同じ場所の会話でも、話している対象が変わったら別の話題にします。
- 返信していても、同じ話題とは限りません。返信の中で対象が変わったら、新しい話題にします。逆に、返信していなくても、前に出た話題の続きなら、その話題に入れます。
- 日をまたいで、前の話題の続きが出てくることがあります。そのときは前の話題に入れます。
- 相づちや反応（「いいね」「へー」「おつかれさま」など）は、反応している投稿の話題に入れます。
- あいさつ、天気、暑さなど、その場の雑談で場所の話題に関係しないものは「雑談」（`OFF`）にします。
- 1つの投稿は、いちばん中心の話題1つに入れます。
- 話題の細かさの目安は「〇〇の歴史」「〇〇への行き方」「〇〇で食べたもの」くらいです。1件だけの話題は、ほかのどの話題とも本当に関係がないときだけにします。

## 入力

投稿の一覧（JSON）。各投稿は `id`、`day`（何日目か）、`author`、`reply_to`（返信先の投稿 id。空のこともある）、`text`。

## 出力

次の形の JSON を、指定されたファイルに書いてください。説明の文章は要りません。

```json
{
  "conversation": "会話の名前",
  "topics": {"A": "話題の短い名前", "B": "..."},
  "assign": {"P1": "A", "P2": "A", "P3": "OFF"}
}
```

- `topics` の記号は A, B, C… の順に付けます。
- `assign` には、入力のすべての投稿を入れます（雑談は `"OFF"`）。
